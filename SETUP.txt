ZENO LIFE MEDICARE — FINAL V5

1. Replace ALL files in the GitHub repository with these files.
2. Keep firebase-config.js with your current Firebase Web App config.
3. Firebase Authentication -> Email/Password must be enabled.
4. Firebase Authentication -> Settings -> Authorized domains must include your exact GitHub Pages domain.
5. Publish the Firestore rules from firestore.rules.
6. After upload, open the site in Incognito or clear site data once so old JS is not cached.

Admin login:
- Admin tab -> enter ADMIN (the package maps this to the configured admin email)
- Password = the current Firebase Authentication password for that admin user.

Important: This package removes the Firestore admins/{uid} read from the Admin LOGIN step.
The Admin dashboard still uses Firestore for customers, medicines, orders, bills, etc.
