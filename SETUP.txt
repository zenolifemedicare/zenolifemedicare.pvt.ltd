Zeno Life Medicare — Final A-to-Z package

1) Upload the contents of this zeno-final folder to the GitHub Pages folder/repository.
2) Firebase Web config is already included in firebase-config.js.
3) Enable Firebase Authentication -> Email/Password.
4) Create Firestore Database.
5) Publish firestore.rules in Firestore -> Rules.
6) Add your GitHub Pages hostname under Firebase Authentication -> Settings -> Authorized domains.
7) If an old page design appears, hard refresh the GitHub Pages site (or open it in a private/incognito window). CSS uses a version query to avoid stale browser cache.

Important: The Firebase Web API key is a client-side configuration value. Do not put service-account JSON or private credentials in this site.
